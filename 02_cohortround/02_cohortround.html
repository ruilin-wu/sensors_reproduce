CohortRound

Discrepancy-Guided Joint Rounding for FPGA DSP
现有硬件让每个 quantizer 独立 round-to-nearest；CohortRound 把同一时刻多个舍入决定作为一个向量问题，使误差在下游主动相消。

核心判断：这是五个方案中机制辨识度最高的方向。它不是选择更多 bit，也不是保存 residual，而是改变 quantizers 之间的联合相关结构。理论来源（dependent rounding / discrepancy）成熟，但将其变成固定延迟 FPGA DSP rounding network 的直接先例目前未找到。最大风险是控制网络可能比省下的 bit 更贵。

1. 核心问题：独立舍入浪费了一个自由度

一个实数落在相邻两个定点格点之间时，可以向下或向上舍入。Round-to-nearest 独立处理每个位置，只最小化每个 local error；即使编译器知道两个误差经过下游后会同号相加或异号相消，它也不会协调选择。

设一个 cohort 中的舍入误差为 δ，它对多输出/频带契约的影响为 Aδ。独立舍入最小化 |δᵢ|，但真正的目标是 ||Aδ||。在 reconvergent butterfly、filter bank、multi-output FIR、matrix-vector 和 cumulant graph 中，局部稍大的误差可能与其他误差抵消，从而允许所有 quantizer 使用更少 bit。

2. 独有机制：Rounding Cohorts

Mechanism A — Cohort extraction

编译器从固定 schedule 中找出可在同一 pipeline window 决定、且下游 sensitivity vectors 存在相反方向的 quantization sites。它们形成一个 rounding cohort，而不是全局巨型 group。

Mechanism B — Joint up/down selection

每个 quantizer 仍只输出 floor 或 ceil，硬件读取被丢弃 fraction 的少量 leading bits，并联合生成 up/down vector r，最小化加权 discrepancy ||A(f-r)||∞。不传输完整 residual，不增加主数据宽度。

Mechanism C — Bias and drift control

对 streaming/recursive DSP，cohort controller 维护很小的 signed debt state，使长期每个 site 保持无偏或满足 prefix-sum bound；同时对每个 invocation 提供 deterministic group error bound。它不是独立 stochastic rounding，也不需要每个 quantizer 一套 RNG。

3. 新算法：Hardware-Constrained Discrepancy Rounding (HCDR)

compile time:
  partition quantizers into cohorts C
  synthesize a small selector topology T_C
  minimize  width cost + selector LUT + state cost
  subject to  disc(A_C, T_C) <= epsilon_C
              same pipeline window / fanout / timing

runtime per cohort:
  observe b leading discarded-fraction bits
  choose r_i ∈ {floor, ceil}
  preserve optional sum / bias constraints
  minimize a certified proxy of ||A_C (f-r)||∞

HCDR 有两个相互配合的新算法对象：

  1. Cohort hypergraph partition：边权同时包含可消除的 sensitivity discrepancy 与布线/时序代价；受限于 pipeline stage、fanout、shared control bits。
  2. Selector synthesis：小 cohort 用 exhaustive truth-table/MILP 得到 oracle；大 cohort 用 pairwise signed matching + bounded-depth tournament，给出相对 vector-discrepancy lower bound 的 gap。

理论贡献可以是：对具有 rank-1 或树结构 sensitivity matrix 的 cohort，构造 constant-depth dependent rounding，使 group output error 小于独立 RTN 的和界，同时保持每个 quantizer 的合法 floor/ceil 和无偏边际。一般图给 approximation bound。

4. 为什么 FPGA，而不是 CPU/GPU

  • 舍入 cohort 是静态 wiring；少量 fraction bits 可直接进入 LUT truth table / comparator tree，与量化器同 pipeline stage。
  • 每条信号仍是不同物理 bit-width，真正减少 LUT、register、memory width 和可能的 DSP packing。
  • CPU/GPU 的 rounding mode 通常是线程/指令级独立状态，难以低成本联合决定多条 lane 的 up/down。
  • 所有 cohort 大小和 logic depth 编译期确定，II 与 latency 固定。

5. 与 FlexBE 的关系

FlexBE 可提供 DFG、固定 schedule 和 bit-true interpreter；需要扩展 quantization-site IR，使 interpreter 暴露 discarded fraction，反向传播多输出 sensitivity vector，并在 Chisel codegen 中插入 cohort selector。FFT butterfly、conv channel sums、cyclic cumulant 和多 reduce pipeline 都可作为 cohort 候选，但这不是 digit-serial 或 AMC 专用机制。

7. 实验与停止条件

  • Positive candidates：reconvergent butterfly graph、multi-output FIR/filter bank、wavelet lifting、MIMO beamforming、heterogeneous convolution channels。
  • Negative candidates：所有 downstream gains 同号且相近的单输出 reduction；这里 cohort 很难优于 RTN。
  • Baselines：truncation、RTN、independent stochastic rounding、static quantization-mode optimization、same-width WLO、ResidueFlow/compensated path。
  • Gate C1：Python oracle 必须在至少三个 kernel 上显示 joint floor/ceil 使所需 fractional width 平均下降 ≥1 bit，同时满足同一 deterministic output bound。
  • Gate C2：综合后 selector + routing cost 必须小于省下 datapath cost的 30%，Fmax 下降低于 5%。
  • Gate C3：不能只给 expected MSE；至少 rank-1/tree special case 要有确定性 bound。
原创性风险：中低；实现风险：高。现有工作分别覆盖 quantization-mode search、stochastic rounding、dependent rounding 和 discrepancy quantization，但未发现将运行时中间值、下游 sensitivity、cohort placement 与 fixed-latency FPGA selector作为一个综合问题的直接论文。真正风险不是“有人完全做过”，而是 selector 节省不了足够硬件。

8. English paper pitch

CohortRound challenges the assumption that fixed-point quantizers should round independently. A compiler groups simultaneously available quantization sites whose downstream sensitivity vectors admit cancellation, then synthesizes a bounded-depth FPGA selector that chooses their floor/ceil outcomes jointly. Our hardware-constrained discrepancy-rounding algorithm co-optimizes cohort placement, selector topology, signal widths, and pipeline timing while enforcing deterministic group-error and long-run bias bounds. CohortRound reduces physical precision by shaping the correlation of quantization errors, without carrying residual values or changing initiation interval.

Verdict: agree with the self-assessed ranking — this is the mechanically cleanest, most distinct mechanism of the five (joint correlation structure of rounding decisions, not extra bits, not extra state). The cited lineage checks out: Menard (EUSIPCO 2010, mode selection), Mikaitis (stochastic rounding hardware), Chee et al. One more rung on the lineage ladder

Not fatal, but worth adding for a complete related-work section: statistical "controlled rounding" (Cox & Ernst 1982; Causey, Cox & Ernst, JASA 1985 — verified real) solves the identical abstract problem — jointly round several numbers to preserve a linear constraint — as a transportation/network-flow LP, two decades before Gandhi et al.'s CS-theory treatment. Different application domain (census tables), so a DAC reviewer won't flag its absence, but it's the actual root of the idea, one level before dependent rounding.

An underweighted implementation risk

Gate C2 checks Fmax drop from selector+routing cost, but the hazard is upstream of what that measurement can see. A cohort selector reads "leading discarded-fraction bits" from multiple quantizers that, in a pipelined FPGA design, are not necessarily physically adjacent — they sit wherever the floorplanner and P&R tool put them, potentially on opposite sides of the die if a cohort spans separate butterfly stages or output channels. A one-cycle joint decision means those bits must converge combinationally to one small selector and the up/down decision must propagate back out — a routing-congestion and Fmax risk the pre-route LUT/area cost model in HCDR's cohort-hypergraph partitioning cannot see, because it only shows up post-place-and-route. Gate C2 should require post-P&R timing, not synthesis-only, before wiring cost is allowed to enter the partitioner as a static edge weight.

A cheap gate missing before any RTL

The pitch treats cohort size as a free knob trading savings against selector cost but doesn't bound what cohort sizes actually occur on real DFGs. If cohorts collapse to size 1-2 on the target benchmarks, CohortRound has nothing to redistribute — the same degeneracy that sank exchange-group sizing for a structurally similar reason in the ISOCYCLE/ResidueFlow debate (debate.md Gate 2). Add a "cohort-size distribution on real kernels" oracle as the very first, Python-only gate.

Recommendation: keep. Strongest standalone mechanism of the five; tighten Gate C2 to post-route timing and add the cohort-size oracle before committing engineering effort.

最终题目

CohortRound: Sensitivity-Guided Joint Rounding Synthesis for Fixed-Latency FPGA DSP

我们解决什么问题

fixed-point compiler 通常让每个 quantizer 独立 round-to-nearest，最小化各自 local error。但在 FFT butterfly、multi-output FIR/filter bank、matrix-vector、convolution reduction 和 cumulant graph 中，多处 rounding errors 会在下游重汇合。独立最优不等于最终输出最优：适当相关的 floor/ceil decisions 可以让误差沿 sensitivity directions 主动相消，从而允许更窄 datapath。

突出原创性

controlled rounding、dependent rounding、stochastic rounding 和 discrepancy theory 都不是新概念。原创性在于：一个新的 compiler+hardware object——从 scheduled DSP DFG 中联合发现 physically feasible cohorts，依据 downstream sensitivity 综合 fixed-latency runtime selector，并与 widths、routing、alignment 和 FPGA PPA 共同优化。正式论文在完成系统检索前只写“未发现直接先例”。

新机制与新算法

HCDR 构建 cohort hypergraph：节点是 quantization sites；hyperedge 同时编码同一 decision window、sensitivity cancellation potential、physical locality、fanout 和 alignment cost。运行时 selector 只读取被丢弃 fraction 的少量 leading bits，输出相关 floor/ceil vector。

compile time: choose cohorts, widths and bounded-depth selectors
runtime: r = Selector(discarded_prefixes, optional_debt)
objective: minimize FPGA cost subject to ||A(f-r)|| <= epsilon

无状态 selector 给出 per-invocation group discrepancy bound；可选 small debt state 给出 bounded prefix/cumulative bias。除非显式加入随机机制，不声称 unbiased marginal。

最终贡献

  1. 提出 runtime intermediate quantizers 的 sensitivity-aware cohort abstraction；
  2. 提出 cancellation-and-locality hypergraph partition 与 feasibility oracle；
  3. 提出 bounded-depth joint rounding selector synthesis 及确定性误差界；
  4. 把 placement-aware proxy、post-route calibration 与 word-length saving 纳入同一编译流程。
